# artifacts/

Source HTML for artifacts published to claude.ai. The published page is the thing people read;
this directory is what it was built from, so a later session can revise and republish instead of
rebuilding from scratch.

Each file is body content only — no `<!doctype>`, `<html>`, `<head>` or `<body>` tags. The
publisher wraps it. To update a published page, edit the file here and republish it **to the same
URL**; a new path claims a new URL.
