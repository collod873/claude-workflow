# The lane map

Every lane on one page: 24 lanes, 8 of them spending a model, drawn from
[`shared/lane-wiring.ts`](../../.Workflow/agent-workflows/shared/lane-wiring.ts) and the code each lane
runs. Generated by `npm run lane-map`; regenerate it, never edit it. Each box links to the lane's
walkthrough in the table below. A **box** is a lane; an **arrow** is the event that wakes the next one, and an
arrow that leaves a lane for nowhere is a stop.

Run counts are collod873/claude-workflow's Actions API, 2026-08-23 to 2026-09-06. "Skipped" is a run
that fired, evaluated its gate, and did nothing. A faded, dashed box did no work in the window.

Amber is a lane that spends a model; blue is deterministic TypeScript; grey pills are the outside world,
you included. A red line inside a box is a stop: a label the lane writes that no lane reads, so the ticket
waits for you. A dashed arrow is a ring back up the page.
