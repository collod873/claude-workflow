# The machine may file defects against itself but never features

A run that hits a defect in the machinery — a misfired lane, a gate that failed open, a publisher writing the wrong edge — files it as a `bug` at lane 00. A run with an *opinion* about how the machinery could be better files nothing. There is no tenth lane. A machinery defect is filed in **this** repo whichever repo the run was working in; it never edits the machinery from inside the repo it was dispatched into.

A defect is a failure that already happened, checkable outside the agent that found it; a feature is an opinion, and opinions about the machinery are where August's 82% machinery share came from.

**Rejected:** a tenth lane with its own queue and cap — it legitimises the machine as a customer, then has to be rationed.

**Accepted cost.** The owner files machinery improvements himself, from lane 00.
