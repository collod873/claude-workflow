# The machine runs on standard hosted runners, and minutes are the owner's to watch

The machine runs in GitHub Actions on standard hosted runners, so the owner's PC never runs it and
he follows Specs and tickets in the GitHub app. Speed comes from the machine doing less, not from
bigger hardware: no self-hosted or paid runner type unless the difference is massive. Lumaria stays
private, since its code is the product and public code cannot be taken back, and its overage
minutes are paid. No spending cap, alert or minutes monitor is built, and no session raises minutes
again: the owner watches them himself.

**Rejected: running the machine on the owner's PC, or on larger paid runners.** Both buy speed the
machine should earn by doing only what is needed.

**Rejected: making Lumaria public for free minutes.**

Evidence: `docs/research/owner-rules-2026-10.md`, N9 and C3.
