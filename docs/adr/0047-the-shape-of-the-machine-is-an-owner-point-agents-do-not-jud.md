# The shape of the machine is an owner point: agents do not judge whether a mechanism should exist

Which mechanisms exist, where agents sit, and where a check goes are the owner's call — a third owner point in `GOAL.md` §2. Agents are reliable at building a mechanism and unreliable at asking whether it should exist, because the thing under review is their own work.

The record supports it: the governor survived five days of agent review and died to a single owner question. Across that window twenty owner touches were rubber-stamps and five were engagements — all five killed a mechanism, and no agent-originated review ever has.

**Rejected:** folding shape into destination and scope — scope is how much to build, and the governor cleared every scope question it was asked; and a skeptic agent, which is still an agent scoring an agent's design.

**Accepted cost.** It is answered at intake, not at review, so it adds no venue.
