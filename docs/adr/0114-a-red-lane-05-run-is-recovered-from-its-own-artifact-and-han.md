# A red lane 05 run is recovered from its own artifact and handed to Verify, and the third recovery of one ticket reaches the owner

When `Implement` completes red, a lane that spends no model reads the run's `implementer-answer-<n>` artifact, lands it on the ticket's branch, opens the pull request and dispatches `Verify`. A red run with no artifact is re-dispatched as `ticket-ready`. Either way it leaves one marked comment; the third labels the ticket `needs-human` and assigns the owner.

Over seven days: 22 failed runs, 7 of them `Implement`, no automatic repair. The fixer listens to `Verify` alone, so a run dying before its push never reaches the repo's only repair, and its work survived only as an artifact whose sole reader was a person rebuilding the branch by hand.

**Accepted cost.** Recovery does not diagnose: a red whose cause is the ticket, spec or test is recovered, judged red again, and reaches the owner at the cap with its evidence.
