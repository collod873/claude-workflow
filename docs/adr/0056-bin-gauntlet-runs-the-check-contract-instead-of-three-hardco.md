# bin/gauntlet runs the check contract instead of three hardcoded tools, and the contract is generated rather than written

Recorded 2026-08-26.

Status: superseded by ADR-0087

`.claude/contract.json` stays. It stops being hand-written and starts being **generated by probing
the repo**, and `bin/gauntlet` stops hardcoding `tsc`/`eslint`/`vitest` and starts **running
whatever the contract names**. The generator and the runner are the two readers that make the file
survivable; without them it is not.

Ruled by the owner 2026-08-26, with [#82](https://github.com/collod873/claude-workflow/issues/82).

## The question had already half-answered itself

[#34](https://github.com/collod873/claude-workflow/issues/34) was declined by `DESIGN.md` §10 on
bootstrap-expiry grounds — *"this repo does not grow files to serve era-6 skills"* — and then
**overtaken by events**: commit `d42508c` created `.claude/contract.json` on 2026-08-26, one day
before this decision, because a `/drain` run had no other way to learn the definition of green.
#34's four criteria are all met by that commit and it is closed. So *"does it return"* was never the
live question by the time the frontier reached it. **It had returned, hand-written, with no reader
— which is the state this ADR is about.**

[ADR-0045](0045-a-superseded-adr-is-named-by-a-trailer-its-successor-writes.md) had already ruled
against exactly that state, in passing, one day later still: *"the difference from `contract.json`,
which had no reader that could tell a stale manifest from an accurate one."* And `CLAUDE.md` carries
the obligation in plain sight — *"a change that moves the definition of green moves
`.claude/contract.json` in the same commit"* — which is an active ritual, the thing `GOAL.md` C4
bans by name. The file was live and non-compliant with this repo's own charter on the day it landed.

This ADR does not reverse ADR-0045. It satisfies the test ADR-0045 stated: **the maintenance
obligation has to be the thing the mechanism watches.**

## The reader was free, and fixing the file fixes portability in the same stroke

`bin/gauntlet` resolves three binaries from `node_modules/.bin` and exits 2 if any is missing.
[`docs/research/gauntlet-portability-2026-08.md`](../research/gauntlet-portability-2026-08.md)
measured what that costs: **exactly one of nine repos satisfies the precondition**, and the blocker
is not that the others are not JavaScript. `claude-ds` is TypeScript with `tsc`, `vitest`, an
`npm run verify` aggregate and a four-step CI job, and would exit 2 **forever**, because its linter
is biome. *The third hardcoded tool is a vendor choice, not a check category.*

Pointing the gauntlet at the contract does both jobs with one change:

- **It gives the file a reader.** A slot naming a command that no longer works is `exit 2` at every
  venue, on every turn — the gauntlet's existing third exit code (*"the checks could not run — a
  broken gauntlet, never reported as a finding"*) doing precisely what it was built for. The
  contract can no longer be quietly wrong about a command, because the command is what runs.
- **It unhardcodes the vendor.** The preflight checks the contract's commands rather than three
  binaries, which takes the gauntlet from one of nine repos to roughly eight of nine.

It also dissolves a complaint the research recorded: Lumaria's contract declares `stop: null`
because *"Lumaria's fast check is session-scoped lint in `.claude/hooks/stop-gate.sh`, which the
contract can't express."* Under a runner that executes `cmd`, a command is a command;
`.claude/hooks/stop-gate.sh` is expressible and always was.

## The schema is era 6's, unchanged, with one constraint added

The six slots — `stop`, `test`, `test_one`, `typecheck`, `lint`, `all` — the `{"cmd", "why"}` shape,
and `{"cmd": null, "why": "..."}` as the sanctioned opt-out are all inherited verbatim from era 6:
`agent-skills` ADR-0006 defined the contract as a thin invocation layer, and its ADR-0022 added the
sixth slot. **Nothing is renumbered, renamed or removed, so every existing contract in the estate
stays valid and the global `hooks/stop-gate.py` keeps reading the file it already reads.** What
changes is who writes it and who reads it, not what it says.

One constraint is added:

> **`why` names a declaration site, never a measurement.**

PWPP-Projects' contract drifted **entirely inside `why`** — *"verified green 2026-07-31, 23s"*,
measured at **39.49s and not green** four weeks later — while its `cmd` stayed correct throughout. A
pointer like `package.json#scripts.test` or `pytest.ini#testpaths` is checkable and does not rot; a
stopwatch reading always does. Wall-clock is what the gauntlet measures at run time against its own
venue budgets, and it already reports itself when it overruns. A number in `why` is a second,
unwatched copy of a fact the runner holds live.

## What generation buys that a reader alone cannot

Running the contract catches a **wrong** command. It cannot catch a slot that lies by being
**empty**, and that is not hypothetical: 3D-Printing declares `test: null` / *"No repo-level test
suite"* while `tests/test_model_search.py` sits in the tree, mocks HTTP at a single transport seam,
and passes nine tests in **0.30s** — inside the in-turn budget. Nothing runs, so nothing fails, so
nothing notices. Two of the estate's four contracts are wrong about their own repo and this is one
of the two.

So the contract is **generated by probing the repo**, and a `null` it writes is a `null` it
measured. The standing check is then `regenerate && diff` — deterministic, no model, free, and it
belongs in the push venue. A repo that has grown a test suite since the last install goes **red**
rather than quietly lying about itself.

That is ADR-0045's survivability test satisfied: forgetting to update the contract is the thing that
gets detected, so nobody has to remember. It is also the property
[ADR-0048](0048-the-close-gate-s-reconciler-rides-session-end-because-a-cron.md) and `DESIGN.md` §6
already rely on elsewhere — recomputed, never stored, so nothing it says can go stale.

**`CLAUDE.md`'s same-commit rule is retired by this**, and should be struck when the generator
lands. It was the ritual; the generator is what replaces it.

## Where a venue needs a form the schema has no slot for

The `turn` venue lints a single file, and the era-6 schema carries `test_one` but no `lint_one`.
**No slot is invented.** Where a venue needs a narrower form the contract does not carry, the
gauntlet runs the **broader** slot and reports the cost.

It degrades to a slower check, never to no check. A gate that skips is `CONTEXT.md`'s **Fail-open**,
which ADR-0053 restated as the stronger rule for the immutability job — a check that skips is not a
gate. Deferring the schema change also keeps this ruling from forcing an edit on four other repos'
files before anything has been built to need it.

## Consequences

**This moves the definition of green, so it moves the contract in the same commit** — the last time
that rule is honoured by hand, since the same commit is what retires it.

**Every non-Node repo in the estate becomes gauntlet-checkable**, which is the input `DESIGN.md`
§11's question 1 needs on the day it reopens. Its standing recommendation is *"the gauntlet and the
cross-repo counter only"*, and until this ruling the gauntlet half of that recommendation could not
actually be honoured anywhere but here.

**Vocabulary: "the contract" unqualified is retired.** Two different things carry the word — the
six-field prose collapse of a shipped lane
([ADR-0025](0025-design-md-carries-no-lane-status-a-shipped-lane-collapses-to.md), across nine
`DESIGN.md` sections) and this JSON file. `CONTEXT.md` gains both as **lane contract** and **check
contract**, and neither is referred to bare. Renaming the file was considered and rejected on
measured cost: **18 files in `agent-skills` read `.claude/contract.json`**, including the live global
`hooks/stop-gate.py` that fires at every turn-end in every repo, plus `bin/lint`, `bin/clone-check`,
`bin/re-seed` and the `drain`, `implement` and `setup-matt-pocock-skills` skills — and four repos
carry the file itself. A prose disambiguation costs nothing and fixes the actual failure, which was
the unqualified word rather than the filename.

**The honest remaining hole:** a probe that cannot see a check is indistinguishable from a check that
is not there. Knowledge-Base is the shape — 229 tests, collection errors in 4 of 40 files, and a
suite that does not terminate — and a generator will write `null` for it and be defensibly wrong. The
trade is accepted because a wrong `null` that a re-probe will overturn the moment the repo is
runnable is strictly better than a wrong `null` nobody will ever re-examine, which is what the
estate has today.

## What would reverse this

A repo whose real definition of green cannot be expressed as a command, which would mean the
invocation layer is too thin rather than that generation was wrong. Nothing in the nine surveyed is
that shape.
