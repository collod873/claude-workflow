# An obvious fix goes straight in, and a gate is proven first

A rule that will plainly improve things is built at once, as a changed default at its cause. A
rule still in doubt enters as a meter and earns its way. Anything that would stop work proves
itself on real runs first, and when it fires it hands the work back to the step that made it.

**Rejected: every rule entering as a meter.** Obvious fixes waited out 30 merged PRs, and the owner
asked on 2026-10-06 for fixes over "a hopeful prompt".

**Rejected: a gate on the owner's say-so.** Stopping work is costly enough to need evidence of
where and how it should fire.
