# A model may translate evidence into a gate's grammar but never render the gate's verdict

Where a gate needs a record its subject did not write, a model may read whatever evidence exists and express it in the gate's grammar; the gate then judges that output by the same deterministic rules it judges a hand-written one. The model translates; the grammar decides. Nothing a model says is ever itself a verdict.

A commit-keyword, phone or web-UI close has no agent to be told to post a `## Closing record` first, and `no-closing-record` was already 78 of era 6's 125 refusals.

**Rejected:** an amnesty judge — one model deciding whether a record-less close was legitimate anyway. It ends the gate: it would wave through most of the volume. Also rejected: refusing deterministically, which reopens every commit-keyword close.

**Accepted cost.** A well-shaped lie still passes; telling the salvage prompt that unevidenced means UNMET is a mitigation, not a mechanism. The seam generalises to lanes 04 and 06.
