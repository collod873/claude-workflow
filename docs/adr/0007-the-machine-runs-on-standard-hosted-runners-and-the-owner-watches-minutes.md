# The machine runs on standard hosted runners, and the owner watches minutes

The machine runs in GitHub Actions on standard hosted runners, so it runs off the owner's PC and he
follows Specs and tickets in the GitHub app. Speed comes from the machine doing only what is
needed; a different runner type earns its place only by a massive difference. Lumaria stays private
and its overage minutes are paid. The owner watches minutes himself, so sessions spend their effort
on the machine running well.

**Rejected: the owner's PC, or larger paid runners.** They buy speed the machine should earn.

**Rejected: a spending cap, alert or minutes monitor.** Machinery for a question the owner settled.

**Rejected: making Lumaria public for free minutes.** Public code cannot be taken back.
