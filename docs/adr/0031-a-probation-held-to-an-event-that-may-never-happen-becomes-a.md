# A probation held to an event that may never happen becomes a count

Lane 01's refuter is retired on a count, not on a convening: at the 20th sheet posted with zero surviving refutations, the counter files an issue proposing its deletion.

It binds because §6 held the refuter to the backwards question "at the event that would add another agent to this lane", and nothing schedules that event, so the probation could never fire. Generalised: anything on probation here needs a firing condition triggered by something that happens on its own, or it is not on probation.

**Rejected:** a monthly clock, forbidden by ADR-0004; and keeping the unscheduled event, which is not a condition.

**Accepted cost.** The counter files an issue and never deletes the stage, so the refuter's death reaches the owner as work he rules on. A declined proposal re-proposes only once the count has grown.
